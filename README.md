#Budget Buddy

i. 
Budget Buddy is a personal application that was created using python, streamlit, and matplotlib. It helps the user to track monthly incomes and expenses.

ii.
1. Copy the repository in github.
2. venv, matplotlib, and streamlit should be installed.
3. Create virtual environment with -
    python3 -m venv SP1.
4. Activate virtual environment in the terminal by pasting-
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser 
    SP1\Scripts\activate
5. Open streamlit by typing the text at the bottom in the terminal-
    streamlit run main.py

iii.
I wasn't able to put an error or safety net if there's a situation where there is a planned amount for a certain budget bucket but there is no actual expense for that budget bucket.
